# The Reading Compass

**An AI-powered personalized reading companion.**

The Reading Compass helps readers discover what to read, understand why a book suits them, prioritize their TBR lists, and build personalized learning journeys.

## Vision

To make reading more intentional, personalized, and rewarding through a combination of recommendation systems, semantic search, and AI-powered assistance.

## Core Features

- Personalized book recommendations.
- Intelligent TBR prioritization.
- Book discovery and search.
- Dynamic reader profiles.
- Goal-oriented reading journeys.
- Explainable recommendations.
- AI-powered reading assistant.
- Reading progress and goal tracking.

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | React + Tailwind CSS |
| Backend | Python + FastAPI |
| Database | PostgreSQL + pgvector |
| Recommendation Engine | Scikit-learn + Sentence Transformers |
| AI Integration | LLM provider behind an adapter |
| Testing | Pytest, Vitest, Playwright |
| CI/CD | GitHub Actions |
